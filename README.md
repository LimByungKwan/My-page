- 첫 화면: 소개, 활동 요약, 공개 근거 링크.

- 관심사: 3D 배경 모델링, 세계사, 뇌과학, 클래식 음악, 운동.

- 공개 범위: 공개·비공개 항목 점검표.
- 상호작용: 관심사 상세 설명을 펼치고 닫는 `details`·`summary` 요소.

## 접근성과 화면 구성

- 제목은 `h1 → h2 → h3` 구조로 구성했습니다.
- 본문 바로가기 링크와 키보드 초점 표시를 제공합니다.
- 관심사 펼치기는 기본 HTML 요소를 사용해 마우스 및 Enter·Space로 조작할 수 있습니다.
- `prefers-reduced-motion: reduce` 설정에서는 부드러운 스크롤을 끕니다. 반복하거나 크게 움직이는 애니메이션은 사용하지 않습니다.
- 외부 웹 폰트 대신 시스템 글꼴을 사용합니다.
- 주요 글자·배경 색 조합의 대비율은 최소 약 **5.13:1**로, 일반 글자 기준 4.5:1을 충족합니다.

### 화면 가로 넘침 검사

각 해상도에서 다음 식을 실행했습니다. 두 화면 모두 `true`였습니다.

```js
document.documentElement.scrollWidth <= window.innerWidth
```

### 움직임 줄이기 설정 확인

다음 식의 결과가 `true`인 것을 확인했습니다.

```js
matchMedia('(prefers-reduced-motion: reduce)').matches
```

이 결과는 설정이 브라우저에 전달됐음을 뜻합니다. 상단 메뉴 이동 시 실제 스크롤 효과가 감소하는지는 별도로 확인합니다.

## 개인정보·비밀값 검사

- 공개 범위와 페이지·제출문 내용을 비교하고 전화번호·이메일·비밀값 패턴을 검색했습니다.
- 배포 파일 및 새 사이트의 Git 기록에서 비밀값 패턴은 발견되지 않았습니다.
- GitHub 저장소의 검증 시점 커밋 `786cc0eda90f9ce4dd5544d33cfcad9820cc80ed`를 기준으로 **7개 커밋·10개 과거 파일 객체**를 추가 검색했으며 비밀값 패턴 발견 건수는 **0건**이었습니다.
- 검사는 당시 저장소 상태와 검색 패턴의 범위에 대한 기록입니다. 이후 새 커밋에 파일을 추가하면 해당 변경도 확인해야 합니다.
- 화면 캡처는 검증 자료로 보관하며, 비밀번호·토큰 원문은 제출물에 넣지 않습니다.

## 짧은 확인 방법 4줄

1. **어디로 가나요:** 공개 결과물 URL을 열고 상단 ‘관심사’로 이동합니다.
2. **무엇을 하나요:** ① 관심사 제목을 클릭해 펼칩니다. ② 다시 클릭해 닫습니다. ③ Tab으로 같은 항목에 초점을 옮겨 Enter 또는 Space로 펼칩니다.
3. **무엇이 보이면 통과인가요:** 마우스와 키보드에서 같은 상세 설명이 열리고 닫히며, 키보드 초점이 표시됩니다.
4. **안 될 때 무엇이 보이나요:** 접속 오류나 로그인 요구가 나타나거나, 설명이 열리지 않거나, 키보드 초점이 보이지 않습니다.

## AI와 나의 판단 3줄

1. **AI에게 맡긴 일:** 페이지 코드 작성, 자기소개 자료의 문장 정리, 첫 화면 배치 보완, 제목·명암·비밀값 패턴 검사를 맡겼습니다.
2. **직접 판단한 일:** 공개 범위를 정하고 실제 경험 3개를 제공했으며, 시크릿 접속·두 해상도·링크·키보드·콘솔 결과를 직접 확인했습니다.
3. **AI 제안을 따르지 않은 일:** 명시적으로 따르지 않은 제안은 없습니다. 공개 범위와 경험 문장을 검토하고, 실제로 겪은 내용에 맞게 확인·수정한 뒤 반영했습니다.
