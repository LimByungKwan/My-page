# 임병관 — 한 페이지 소개

T01 카드 1~2 단계의 개인 소개 페이지입니다. 사용자 승인 범위에 따라 이름, 가치, 관심사, 학습 방식과 사용자가 직접 설명한 실제 경험 3개를 반영했습니다.

## 카드 2

- 정보처리기사: 손코딩을 하며 로직을 그려 공부했고 최근 최종 합격함.
- 언리얼 게임 개발: 워프 시 캐릭터가 바닥 아래로 내려가는 문제를 워프 위치를 조금 더 위로 조정해 해결함.
- 뇌과학 독서: 몰입과 관련해 편도체 안정화·전두엽 활성화라는 개념을 알게 됨. 실제 집중력 향상이나 별도 필기 결과를 주장하지 않음.
- 과제의 허용 형식인 관찰 가능한 결과 문장을 이용해 언리얼 수정 전후 결과를 경험 항목에 연결함. 코드·영상·합격증을 독립적으로 검사한 것은 아님.

## 실행 및 GitHub Pages

dist/index.html을 브라우저에서 열 수 있습니다. GitHub Pages에는 dist 폴더 안의 index.html, style.css, script.js를 저장소 루트에 올립니다.

## 검증 상태

- 대상·목적 한 문장과 공개 5개·비공개 6개 항목을 페이지에 표시했습니다.
- 사용자에게 공개 범위 승인을 받았습니다.
- 링크 대상과 기본 파일 구조를 정적으로 검사합니다.
- 실제 브라우저 해상도, 키보드, 콘솔 검사는 아직 완료하지 않았습니다.
- 카드 3~5 전체 통과를 주장하지 않습니다.
- GitHub의 새 고정 커밋 소스 URL은 업로드 후 확인해야 합니다.
